## Supabase テーブル設計

```sql
create table diagnosis_sessions (
  id                    uuid        primary key default gen_random_uuid(),
  created_at            timestamptz default now(),
  full_name             text        not null,
  job_title             text,
  company_name          text,
  industry              text,
  recommended_tool      text,
  score_chatgpt         integer,
  score_copilot         integer,
  score_gemini          integer,
  readiness_score       integer,
  estimated_time_saving text,
  form_data             jsonb       not null,
  result                jsonb       not null
);
alter table diagnosis_sessions enable row level security;
create policy "service_role full access" on diagnosis_sessions
  for all using (auth.role() = 'service_role');
```

完全な手順は `docs/supabase-setup.md` を参照。

## 想定削減時間ロジック

業務別の月間削減時間基準値（例：メール作成=5h、会議メモ=6h、提案書=8h）に対し、
導入準備度スコアによる倍率（0.5〜1.0）をかけて「月○〜○時間」形式で算出。

```
倍率 = 0.5 + (readinessScore / 100) * 0.5
low  = round(mid * 0.7)
high = round(mid * 1.4)
→ 「月{low}〜{high}時間」
```
